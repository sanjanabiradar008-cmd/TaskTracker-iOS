# TaskTracker-iOS

A clean, interactive task management application built natively for iOS and iPadOS using SwiftUI. 

## 🚀 Features
- **Dynamic State Management:** Uses `@State` properties to update UI checkboxes and task status in real time.
- **Interactive UI:** Features custom completion animations, green check marks, and dynamic text strikethrough styling.
- **Dynamic List Streams:** Supports adding new elements dynamically through custom data input fields.
- **Gesture Control:** Includes native swipe action integration to modify and manage tasks.

## 🛠️ Tech Stack
- **Language:** Swift 5.x
- **Framework:** SwiftUI
- **Environment:** Swift Playgrounds / Xcode
